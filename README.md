# ことばつなぎ — コンテスト提出候補（部分公開）

## 作品概要
ことばつなぎは、高齢者と医療者のオンラインでの会話を、使いやすい操作画面と字幕で支援する開発中の作品です。このリポジトリは、開発中の実アプリから選んだ画面補助コードの部分公開候補です。完成した通話アプリやAI変換システムの配布物ではありません。

## 公開範囲と構成
- public/patient-accessibility.mjs / .css: 患者画面の文字サイズ（100・150・200%）、同意操作、固定操作ボタン、状態案内。
- public/answer-call.mjs: 応答中の二重操作防止、進捗表示、失敗後のボタン復帰。
- public/previsit-error.mjs: 問診票を開けない場合のエラー種別に応じた案内文。
- tests/: 上記に対応する既存の単体テスト。文字サイズ・同意のテストは元のファイルから独立実行できる2件を抽出しています。
- PUBLIC_FILES.json: 公開ファイルのSHA-256一覧（この一覧自身を除く）。

実装4ファイルは、開発版の実コードから選定しました。3ファイルは無変更で、answer-call.mjsは深い点検で見つかった進捗表示の例外時にボタンが復帰しない問題を修正しています。対応する回帰テストを追加しました。架空の見本実装や代替の通話・AIモックは追加していません。テストに使うセッション識別子や状態オブジェクトは、既存テストの試験用値です。

## 実行方法
Node.js 24系を用意し、このフォルダーで次を実行します。Windows・Node.js v24.22.1で11件の単体テストを確認しています。Node.js 22系での実行は未検証です。

~~~sh
npm test
~~~

外部パッケージのインストール、APIキー、ログイン、ネットワーク接続は不要です。直接実行する場合は次のコマンドを使います。

~~~sh
node --test tests/answer-call.test.mjs tests/patient-accessibility.test.mjs tests/previsit-error.test.mjs
~~~

これは単体テストの実行方法です。Web画面を起動するエントリーポイントは含みません。ブラウザー用モジュールの組込みには、元アプリ側のDOM、イベント処理、コールバックが必要です。文字サイズ・同意のテストはDOM全体の表示や実際の権限検証までは確認しません。

含めないもの: 通話・AI・サーバーの内部実装、プロンプト、辞書と参照資料、設定・認証情報、録音、患者・利用者データ、評価原本、画面キャプチャ、内部設計・運用資料、開発Git履歴。

この制限により、審査員は公開部分の実コードと単体テストを確認できますが、作品全体の起動・通話・AI精度の再現はできません。コンテストが全体の再現可能性を要求する場合、この候補だけでは要件を満たしません。

## 組込み時の前提
- mountAnswerCallにはbutton、getSession、answer、onAcceptedを渡します。onProgress、onFailure、unlockは任意の同期コールバックです。answerとonAcceptedの完了は待機します。外部通信のタイムアウトや実際の通話開始は呼出し側の責任です。
- mountPatientAccessibilityはブラウザー専用です。root内のcallStart、callEnd、ラベル内のcallConsent、access内のloginMsg、callBoxと、既存の開始処理が必要です。これは画面上の補助で、サーバー認証や参加権限の検証を代行しません。
- intakeOpenFailureMessageは案内文を返すだけで、送信処理や再送制御は行いません。画面上の「録音しません」「再送しません」という文言だけで、組込み先全体の動作を保証するものではありません。

既存テストと追加の回帰テストは、関数単位の振る舞いを検証します。実際の医療利用、全画面の完成、音声・映像・AI処理の安全性や精度を証明するものではありません。

提出対象はPUBLIC_FILES.jsonとその一覧内の計12ファイルです。.gitignoreも許可リストにし、資料・録音・秘密設定などの新規ファイルを通常のgit addで取り込まない構成にしています。対象を増やすときは、権利・秘密情報・開示範囲を再点検して一覧を更新してください。
